# Exports & Presentation Artifacts

This directory houses published deliverables, presentation decks, and visual report captures from the **Global Billionaire Wealth to GDP (2026)** analytics project.

---

## 📁 Directory Structure

```
exports/
├── published_assets/       # Static executive deliverables (PDF decks, PowerPoint presentations)
├── report_screenshots/     # High-resolution Power BI canvas captures and visual viewports
└── README.md               # Folder manifest and publishing guidelines
```

---

## 📋 Folder Purpose & Guidelines

### 1. `published_assets/`
- Intended for compiled executive briefing decks, PDF report exports, and printed data manifests.
- Recommended naming convention:
  - `Global_Billionaire_Wealth_2026_Executive_Briefing_v1.0.pdf`
  - `Global_Billionaire_Wealth_2026_Summary_Deck.pptx`

### 2. `report_screenshots/`
- Stores PNG / JPEG screenshots of Power BI report pages for documentation, GitHub previews, and PR visual reviews.
- Recommended resolution: 1920 × 1080 (16:9).
- Recommended naming convention:
  - `01_Executive_Overview.png`
  - `02_Macro_Wealth_to_GDP_Matrix.png`
  - `03_Industry_Hegemony_Treemap.png`
  - `04_Demographics_SelfMade_Analysis.png`
