# Security Policy

## Supported Scopes

The **Global Billionaire Wealth 2026** project is an educational, analytical data repository consisting of CSV datasets, Power BI PBIP project definitions, and documentation.

| Component | Supported | Notes |
| :--- | :---: | :--- |
| Power BI Semantic Model (`.tmdl`) | Yes | Integrity of data connectors and M-queries |
| Data Ingestion Pipelines | Yes | Prevention of malicious code injection in scripts |
| GitHub Actions Workflows | Yes | Secrets, runner safety, and script isolation |

## Reporting a Vulnerability

If you discover a security concern, malicious code vector, or vulnerability in any automation script or workflow within this repository, please do not file a public issue.

Instead, please report the vulnerability privately by navigating to the **Security** tab of the GitHub repository and clicking **Report a vulnerability**, or contact the repository owner directly.

Please include:
- A description of the issue and potential impact
- Detailed steps or code snippets to reproduce the issue
- Any proposed mitigations or patches

We will acknowledge receipt within 48 hours and work toward a timely resolution.
